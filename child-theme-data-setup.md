# Alur Isi Data Child Theme Tour2

## Customize

1. Isi **Customize Velocity Theme**:

   1. **Site Identity**: site title, tagline, site icon.
   2. **Header**: Current header
   3. **Color \& Background**
2. **Site Identity**: logo, site title, tagline, site icon.
3. **Theme Color**: sesuaikan dengan warna logo

## Widgets

* Pada **Main Sidebar**: widgets search dengan title "Pencarian", widgets text dengan title dan content Kontak Kami, dan widgets calendar.
* Pada **Secondary Sidebar**: widgets recent posts jumlah "3" dan widgets text: title "statistik pengunjung" dan content statistik \[velocity-statistics].

## Gallery

* Aktifkan fitur **Gallery Post Type** di Velocity Addon.
* Gunakan shortcode **VD Gallery** untuk tampilan halaman gallery.

## Halaman Home

* Set halaman **Home** mengambil template **"Home Template"**.
